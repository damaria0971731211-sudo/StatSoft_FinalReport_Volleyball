## 流程階段

| 階段 | 內容 | 人工決策點（Iris 填） |
|---|---|---|
| Define | 「高估」需要一把尺。定義平台官方級距為常模參照：全體球員實力的標準分數切在 −1.2／−0.4／0.4／1.2 | 是否接受這個官方級距定義：＿＿ |
| Plan | 實力只用比分估（不用自報當先驗，否則循環論證）；主分析＝含測量誤差的序位 probit（切點固定）；輔以配對檢定（Wilcoxon、符號、Stuart–Maxwell、加權 kappa） | ＿＿ |
| Code | 請模擬資料工作線加上性別、球齡、主場與自報偏誤真值（對方已加，並加了 b_skill＝−0.2） | ＿＿ |
| Test／除錯 | D1：序位機率切點索引寫錯（off-by-one），optim 起始值非有限而報錯，已修正。D2：原實力模型所有球員共用 N(0,σ²) 先驗，跨館水準被拉成一樣（V03 真實平均 +0.79、估計 ≈0），改為「主場水準＋個人」的階層先驗後連結成功。D3：先驗沒放球齡，但球齡和實力相關，球齡係數被拉向 0；改為先驗也含性別、球齡（迴歸校準）。D4：發現自由球員的估計實力和真實實力相關只有 0.06（模擬引擎中自由球員實力不影響比分），回報模擬資料工作線後，對方把接發球、舉球、防守也連上實力（引擎 v1.1），重跑後自由球員相關升到約 0.5；仍保留排除自由球員的敏感度分析。D5：比對真值發現模型自己報的標準誤偏小（實際誤差變異約為模型宣稱的 2 倍），用 50 次重複模擬量化這個偏誤對檢定的影響 | 這些修正是否合理：＿＿ |
| Reflect | 見 `self-report-bias/README.md` 的「限制」 | ＿＿ |
